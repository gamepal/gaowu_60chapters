## 1. 角色、层级与材料隔离

### 1.1 两套A／B／C不得混淆

- 正典分层 A／B／C：A 是绝对正典，B 是必须结构，C 是可选实现提示。
- 评分者 A／B／C：A、B 是首轮两名互盲评分者，C 是分差触发时追加的第三名评分者。
- 协调记录必须写明正典层级或评分者身份，不能只写单个字母。

### 1.2 各角色输入

- 主笔：唯一输入为 `第一章重构_封闭主笔包_v1.3.md` 的完整内容。
- 事实与连续性审校：接收匿名正文与 `第一章重构_事实审校任务卡_v1.3.md` 的内容，不接收开篇分数。
- 真人感与反过描写审校：接收匿名正文与相应表达审校口径，不接收开篇分数。
- 评分者 A、B：互盲，只接收 `第一章开篇盲评量表_v1.3.md` 的内联内容与匿名正文内联内容。
- 评分者 C：仅在规则触发时启用，接收与 A、B 完全相同的两份内联内容，不接收触发原因或前两份报告。
- 协调人：唯一可以接触目标、测试路径、版本记录、全部原始报告和本规则的角色。

### 1.3 评分者A、B互盲

1. A 与 B 不知道对方身份，不接触对方分项、总分、证据、评语或消息。
2. A 与 B 不接收主笔包、事实任务卡、事实报告、真人感报告、协调规则、作者身份、正文源文件名或目录路径。
3. 协调人分别以内联正文发送盲评量表与匿名正文；不得发送文件链接、测试根路径、侧边栏文件卡或带路径截图。
4. 内联正文不得带目标分值、流程身份、来源版本、作者信息或其他评价结果。
5. A、B 均提交并锁定原始报告前，不进行尺度校准、分数讨论或相互复核。

### 1.4 评分者C隔离

- C 在提交前不接触 A、B 的分数、证据、身份或分差。
- C 提供第三个独立分数，不阅读前两份报告后选择立场。
- C 的正文 SHA 与量表 SHA 必须与 A、B 完全一致。

## 2. 正典A层、结构B层、提示C层的审校映射

### 2.1 A层显式冲突

A 层问题是正文明确写出或通过行动必然建立了相反正典，包括：

- 时间、地点起点、人物关系、全文姜瑶贴身第三人称、记忆或能力边界被改变；
- M-01 来源、户名、余额、藏处、随身状态、交付支取状态或沈家知识边界发生冲突，包括第一章沈家证实姜瑶关于存折的谎言；
- 沈建业到场、进入内心，或提前处理汇款、婚姻、经营线；
- 姜远身份、救人对象或冲突人物范围被改变；
- 新能力、外力救兵、证人、群众、村干部或巧合证据改变结果；
- A-01 所有权转移，或现金、经营、库存发生变化。

完整前世记忆、原身碎片与唯一坏未来只作为既有能力边界和正文认知上限。正文不提这些内容，不记 P0、P1、P2 或任何缺失；只有显式新增系统、读心、全知预知，或使用超出边界的精确信息时，才按 A 层冲突处理。

A 层显式冲突进入事实审校 P0。

### 2.2 B层关键缺失或实施越界

B 层问题包括：

- 前300缺少索折危机、M-01 来源与权属、存折随身或第一次人格化回击；
- 第一击没有把冲突主动带到堂屋；
- 姜瑶没有在正文谎称存折由姜父保管、需要回柳河核手续；
- 第二击没有按先问金额、再分轮追谁借、谁还、何时还的功能先后推进；
- 沈建勋没有以生意急需为理由，或没有声称周转开后全家或姜瑶会得好处来回避借款边界；
- 第二击已经形成边界清楚、责任可追、还期明确的借款，或整本折子控制主题没有成立；
- 陈丽拒绝孩子钱和自家承担经营债的边界缺失；

- 核谎不是离院兑现后的新命令，抢跑没有发生，或章末已经完成核谎；
- 唯一身体限制、正文篇幅或章后状态连续性没有满足。

B 层关键缺失或实施越界进入事实审校 P1，不直接记 P0，除非正文同时建立了独立的 A 层相反事实。

### 2.3 C层可选提示

以下有无、措辞或实现差异不得单独生成事实问题，也不得进入盲评硬性冲突：

- B 层已锁定生意急需的功能；具体可写价还没定、生意正急、今天错过会丢买卖等家常说法，不要求固定原句；
- 只给口头紧迫感而没有收据、合同、货物、证人等外验凭据；
- B 层已锁定周转后全家或姜瑶会得好处的功能；具体可写全家有好处、姜瑶会得好处、生意周转开后再说等家常说法，不要求固定原句；

不得把今天错过即丢买卖、没有外验凭据、价未定或其他金额回答方式当成 A 层事实基准、盲评 FC 或直接 P0 条件；但必须核对生意急需、周转后全家或姜瑶会得好处这两项 B 层功能。出现具体经营数字不自动构成 P0、P1 或实施越界，只核对该数字全章自洽、不得暴露或使沈家推知 M-01 的 620 元余额，以及可追责借款边界与整本折子控制主题。

## 3. P0、P1、P2定义

同一问题只记一个最高级别。非必写事实未提与 C 层差异不构成问题。

### 3.1 事实与连续性

#### P0：A层绝对正典冲突

- 命中第2.1节任一 A 层相反事实；
- 冲突改变人物身份、资产状态、知识边界、能力边界或全文视角；
- 问题不能通过补充一个 B 层事件恢复，必须改写已建立的正典事实。

#### P1：B层关键缺失或实施越界

- 命中第2.2节任一 B 层问题；
- 正文没有写出相反正典，但必要攻防、顺序、责任结果、空间因果或终局无法确认；
- 问题可在一个核心场景内修复，不需要改变 A 层事实。

#### P2：局部连续性或格式问题

事实方向、B 层结构和章末因果均成立，仅存在可用局部一句或一个字段修复的问题，例如非核心空间指代略含混、一处连接词不足或状态增量遗漏非核心字段。

可不显露的 620 元、暗袋位置、年龄、婚期、就业状态、记忆构成或院门装置名称未出现，不记 P2。

### 3.2 真人感与反过描写

#### P0：全章性失真或生成痕迹泄漏

- 正文泄露提示词、任务清单、评分语言、模型自述或写作过程；
- 全章大面积进入讲解者视角，人物整体变成论证工具；
- 核心结果依赖整排震惊、外力认证、对手系统性降智或机械模板；
- 失真跨越两个以上核心场景，无法局部恢复。

#### P1：重复出现并损伤核心场景

- 两个以上场景重复感官或触感、比喻、心理总结三联链；
- 摸存折、按暗袋、衣料触感等无功能感官反复确认资产或情绪；
- 第二击虽保留功能先后，却写成整齐背诵的固定问答、完整现代论证或连续金句；
- 旁白反复登记谁没有回答什么，替代现场回避与改口；
- 叙述、对白、心理重复同一信息，或三名对手声线大面积同质；
- 姜远牺牲段落膨胀成长篇道德演说或煽情总结；
- 停止索折、开院门、跨门、骑车抢跑的动作被解释性旁白淹没；
- 同类局部问题累计三处或跨两个场景。

#### P2：孤立且可局部修正

只出现一至两处且没有覆盖两个场景，例如一处无功能小动作、一处同义重复、一处现代感偏重用词、一处验收式旁白或局部机械短句。

三个同模式 P2，或同模式问题跨两个场景，必须升级为 P1。

## 4. 匿名载荷与SHA-256锁定

### 4.1 匿名正文载荷

1. 删除文件系统路径、作者名、工作流标签、目标标签和来源版本说明；
2. 保留中性章节标题、完整正文和章后状态增量，不改叙事汉字、标点或段落顺序；
3. 换行统一为 LF，使用 UTF-8 无 BOM，保留一个文件末尾换行；
4. 对精确载荷计算 SHA-256，作为本轮正文 SHA；
5. 锁定后任何改字、改标点、改换行或状态字段变化都生成新 SHA，并使旧 SHA 报告失效。

### 4.2 盲评量表载荷

1. 使用 `第一章开篇盲评量表_v1.3.md` 的完整正文，不附路径、本规则或目标说明；
2. 换行统一为 LF，使用 UTF-8 无 BOM，保留一个文件末尾换行；
3. 对精确内联内容计算 SHA-256，作为本轮量表 SHA；
4. 内容变化时生成新 SHA，并重新派发全部独立评分。

### 4.3 报告SHA要求

- 评分者 A、B、C 的报告必须同时记录正文 SHA 与量表 SHA。
- 事实与真人感报告至少记录正文 SHA；口径文件另有 SHA 时一并记录。
- 任一 SHA 与本轮锁定值不一致，该报告无效，不得修分后继续使用。
- 协调人汇总时先比对 SHA，再读问题级别与分数。

## 5. 有效报告、缺失与污染

### 5.1 独立评分报告有效条件

1. 正文 SHA 与量表 SHA 均匹配；
2. 声明只接触盲评量表内联内容与匿名正文内联内容；
3. 没有接触测试路径、正文源文件名、目标说明、作者身份、其他审校或其他评分者输出；
4. 五个分项为整数，分别落在 20、20、20、25、15 的上限内；
5. 总分等于五项算术和；
6. CJK 计数、正文起止、前300边界、A／B／C判定、硬性退回标记与证据齐全；
7. 每维核心项数量、落档、档内加减分和最终分数可复算；
8. 报告在互盲信息揭示前锁定。

### 5.2 事实与真人感报告有效条件

1. 正文 SHA 匹配；
2. 每个问题只记 P0、P1 或 P2 中一个级别；
3. 每个问题有正文位置、短证据、A／B层级或真人感规则、影响和可执行修法；
4. P0、P1、P2 数量与问题列表一致；
5. 非必写事实未提与 C 层差异没有被误报；
6. 未读取开篇分数后反向调整级别。

### 5.3 缺失报告

- 未提交，或缺少 SHA、分项、证据、隔离声明、层级或问题级别，均视为报告缺失。
- 缺失报告不记零分，不与有效报告合并；协调人向新的独立人员重派同一锁定载荷。
- 评分者 A 或 B 任一报告缺失，评分流程未完成，不能使用另一人的结果单独判断。
- 事实或真人感报告缺失，总放行流程未完成。

### 5.4 污染报告

出现以下任一情况即为污染：

- 评分者看到测试根路径、正文源文件名、目标、本规则或任何非盲材料；
- 评分者看到其他评分者身份、分数、证据或评语；
- 报告锁定前参与尺度讨论或收到暗示性修分要求；
- 使用与锁定 SHA 不同的正文或量表；
- 事实或真人感审校在定级前读取开篇分数并据此调整结论。

污染报告立即作废，不得靠删掉污染段落、口头保证独立或人工修分恢复。评分者 A、B 污染时分别重派新的独立人员；评分者 C 污染时必须重派新的 C，直至取得有效第三评分。

### 5.5 算术错误

- 仅有算术错误且输入、证据、隔离均有效时，评分者可在互盲解除前提交一次带原因的更正；原始记录保留，协调人复算。
- 分档依据、证据或核心项缺失不属于纯算术错误，按缺失报告重派。
- SHA 不匹配按污染或版本错误作废。

## 6. 评分者A／B平均分与放行计算

协调人只使用有效报告，并严格按以下顺序计算：

1. 取得有效评分者 A 与有效评分者 B 后，记录两人的五维分项与总分。
2. 计算 A／B 平均分：`(A总分 + B总分) ÷ 2`。两份总分均为整数，平均分精确记录为一位小数，不在比较前四舍五入。
3. 计算绝对分差：`|A总分 - B总分|`。
4. 若 A 或 B 任一总分低于 90，开篇分数门不通过，不派 C；平均分仍须记录。
5. 若 A、B 均不低于 90，但平均分低于 90，开篇分数门不通过。该条件必须独立记录，不因逻辑冗余而省略。
6. 若 A、B 均不低于 90、平均分不低于 90，且绝对分差不超过 5，开篇分数门通过。
7. 若 A、B 均不低于 90、平均分不低于 90，但绝对分差超过 5，派发评分者 C。
8. 取得有效 C 后，将 A、B、C 三个总分从小到大排序，取中间值作为最终爆款分。
9. 最终爆款分不低于 90，开篇分数门通过；低于 90，开篇分数门不通过。
10. C 缺失、污染或 SHA 不匹配时作废并重派，不能使用无效 C 计算中位数。

## 7. 总放行条件

以下条件必须同时成立：

1. 开篇分数门按第6节通过；
2. 有效事实与连续性报告为 P0=0、P1=0；
3. 有效真人感与反过描写报告为 P0=0、P1=0；
4. 正文为 2100—2300 个 CJK 统一汉字；
5. 全文姜瑶贴身第三人称；
6. 姜瑶已在正文谎称存折由姜父保管、需要回柳河核手续；第一章沈家只怀疑，未证实她撒谎；
7. 第二击按金额、谁借、谁还、何时还的功能先后成立；沈建勋以生意急需并声称周转后全家或姜瑶会得好处来回避，拒绝形成清楚可追责的借款边界，整本折子控制主题成立；
8. 三次攻防、唯一身体限制、停止索折、打开沈家院门、实际离院、兑现后核谎新命令、骑车抢跑且核谎未完成全部成立；
9. 主笔交付、章后状态增量与所有有效报告记录同一正文 SHA；
10. 没有未处理的缺失、污染或版本不一致报告。

P2 可以保留，不单独阻断放行；达到升级规则时必须先升级为 P1。

## 8. 判定顺序

1. 锁定匿名正文 SHA 与盲评量表 SHA；
2. 分别派发评分者 A、B，并独立派发事实与真人感审校；
3. 收齐并锁定原始报告，不互相披露；
4. 验证报告有效性，缺失或污染则重派；
5. 锁定事实与真人感 P0、P1、P2 数量；
6. 计算并记录 A／B 平均分与绝对分差；
7. 执行 A／B 条件，必要时盲派 C 并计算三者中位数；
8. 执行总放行条件；
9. 记录通过、不通过或流程未完成及其直接原因，不用说明替代正文修复。
