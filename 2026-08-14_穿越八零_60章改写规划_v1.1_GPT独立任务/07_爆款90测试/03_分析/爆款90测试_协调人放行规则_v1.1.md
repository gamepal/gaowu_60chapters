# 《穿越八零：军婚女配要翻身》爆款90测试：协调人放行规则 v1.1

日期：2026-08-17  
适用对象：测试协调人  
目标：在输入隔离、版本一致与报告有效的前提下，执行事实、真人感和独立开篇评分的统一放行判定

## 1. 角色与材料隔离

### 1.1 角色

- 主笔：只接收 `第一章重构_封闭主笔包_v1.1.md` 的内容。
- 事实审校：接收匿名正文与 `第一章重构_任务卡_v1.1.md` 的内容。
- 真人感审校：接收匿名正文与反过描写检查口径，不接收任何开篇分数。
- 评分者 A、评分者 B：互盲、独立，只接收中性盲评量表的内联内容与匿名正文的内联内容。
- 评分者 C：仅在规则触发时启用；与 A、B 同样独立，不接收 A、B 的分数、证据或身份。
- 协调人：唯一可以接触目标、测试路径、各类原始报告与最终放行规则的角色。

### 1.2 A、B 互盲要求

1. A 与 B 不知道对方身份，不接触对方分项、总分、证据、评语或消息。
2. A 与 B 不接收协调人规则、主笔包、任务卡、事实报告、真人感报告、作者身份、正文源文件名或任何目录路径。
3. 协调人分别以内联正文发送 `第一章开篇盲评量表_v1.1.md` 的完整内容和同一份匿名正文；不得发送文件链接、测试根路径、侧边栏文件卡或带路径的截图。
4. 内联正文不得带目标分值、流程角色、来源版本、作者信息或其他评价结果。
5. A、B 均提交并锁定原始报告之前，不进行分数讨论、尺度校准或相互复核。

### 1.3 C 的隔离要求

- C 使用与 A、B 完全相同的匿名正文载荷和盲评量表载荷。
- C 在提交前不接触 A、B 的分数与报告，也不接触触发 C 的原因。
- C 的职责是提供第三个独立分数，不是阅读前两份报告后选择立场。

## 2. 匿名载荷与 SHA-256 锁定

### 2.1 匿名正文载荷

协调人从候选正文生成匿名载荷时：

1. 删除文件系统路径、作者名、工作流标签、目标标签和来源版本说明；
2. 保留中性章节标题、完整正文和章后状态增量，不改动任何叙事汉字、标点或段落顺序；
3. 将换行统一为 LF，以 UTF-8 无 BOM 编码，保留一个文件末尾换行；
4. 对这一精确载荷计算 SHA-256，作为本轮唯一的正文 SHA；
5. 锁定后不得再改字、改标点、改换行或增删状态字段。任何变化都必须生成新的正文 SHA，并使基于旧 SHA 的所有报告失效。

### 2.2 盲评量表载荷

1. 使用 `第一章开篇盲评量表_v1.1.md` 的完整正文，不附文件路径、协调规则或目标说明；
2. 将换行统一为 LF，以 UTF-8 无 BOM 编码，保留一个文件末尾换行；
3. 对精确内联内容计算 SHA-256，作为本轮唯一的量表 SHA；
4. 锁定后任何内容变化都必须生成新的量表 SHA，并重新派发全部独立评分。

### 2.3 报告中的 SHA 要求

- A、B、C 的报告必须同时记录正文 SHA 与量表 SHA。
- 事实审校和真人感审校至少记录同一正文 SHA；若审校口径文件另有 SHA，也一并记录。
- 任一报告的正文 SHA 或量表 SHA 与本轮锁定值不一致，该报告无效，不能修分后继续使用。
- 协调人汇总前先比对 SHA，再看分数和问题级别。

## 3. 问题级别 P0、P1、P2

同一问题只记一个最高级别，不重复累计。先判断是否破坏硬正典或核心因果，再判断影响范围；非必写事实未提不构成问题。

### 3.1 事实与连续性审校

#### P0：硬正典或终局破坏

任一项成立即为 P0：

- 时间、地点起点、人物关系、全文视角、记忆与能力边界被明确改成相反事实；
- M-01 来源、户名、余额、藏处、随身状态、交付支取状态或沈家知识边界发生硬冲突；
- 沈建业到场、进入内心，或提前处理汇款、婚姻、经营线；
- 姜远救沈建业在第三次反击之前泄露；
- 新增人物、证人、群众、村干部、巧合证据、外力救兵或新能力改变结果；
- 现金、经营或库存发生变化；
- 沈桂兰没有停止索折，姜瑶没有实际跨出沈家院门，或章末已完成核谎；
- 关键因果无法通过局部修订恢复，必须重写一个以上核心场景。

#### P1：必写事实、空间机制或关键顺序缺失

没有直接写出相反正典，但任一项成立即为 P1：

- 前300缺少索折危机、M-01 来源与权属、存折随身或人格化回击中的任一项；
- 沈建勋的买卖时限、无外验凭据状态、避责策略或整本折子控制目标没有成立；
- 陈丽拒绝孩子钱与自家担债的边界缺失；
- 责任结果被固定问答替代，或金额、借款人、还款责任、还期的回避结果不清；
- 婚房出口、钥匙、院内 A-01、院门内闩、堂屋位置或钥匙转手不足以支撑连续行动；
- 只打开含混的门，未明确打开院门内闩；
- 停止索折、打开院门、实际离院、兑现后新下核谎命令、骑车抢跑的顺序缺失或含混；
- 章后状态增量与正文在核心资产、位置、知识或行动状态上不一致；
- 问题会改变一个核心场景的理解，但可在该场景内修复。

#### P2：局部清晰度或格式问题

满足以下条件才记 P2：事实方向正确，不改变核心因果、人物关系、知识边界和章末状态，且可用局部一句或一个字段修复。典型情况包括：

- 一个非核心空间指代略含混，但不影响院门兑现；
- 一处亲属称谓或资产标签不够清楚，但正文没有建立相反事实；
- 章后状态增量遗漏非核心字段，正文事实本身完整；
- 一处时间或位置衔接需要更清楚的连接词。

可不显露的 620 元、暗袋位置、年龄、婚期、就业状态或记忆构成未在正文出现，不记 P2。

### 3.2 真人感与反过描写审校

#### P0：全章性失真或生成痕迹泄漏

任一项成立即为 P0：

- 正文泄露提示词、任务清单、评分语言、模型自述或写作过程；
- 全章大面积进入讲解者视角，姜瑶贴身叙述失效，人物整体变成论证工具；
- 核心结果依赖整排震惊、外力认证、对手系统性降智或机械模板推进；
- 失真跨越两个以上核心场景，无法靠局部删改恢复。

#### P1：重复出现并实质损伤核心场景

任一项成立即为 P1：

- 两个以上场景重复出现感官或触感、比喻、心理总结三联链；
- 摸存折、按暗袋、衣料触感等无功能感官反复确认资产或情绪；
- 责任攻防写成整齐的固定问答、完整现代论证或连续金句，人物不再像临场说话；
- 旁白反复登记谁没报金额、没认借款、没定还期，替代现场回避与改口；
- 叙述、对白、心理重复同一信息，或三名对手声线大面积同质；
- 姜远牺牲段落膨胀成长篇道德演说、煽情总结或集体表态；
- 停止索折、开院门、跨门或骑车抢跑的关键动作被解释性旁白淹没；
- 同类局部问题累计三处，或分布在两个场景，按 P1 处理。

#### P2：孤立且可局部修正的问题

满足以下条件才记 P2：只出现一至两处，没有覆盖两个场景，不改变人物决策和关键结果。典型情况包括：

- 一处无功能小动作或环境句；
- 一处同义重复、现代感偏重的用词或不自然完整句；
- 一处短暂的验收式旁白；
- 一处节奏机械的单行短句或局部感官堆叠。

三个同模式 P2，或同模式问题跨两个场景，必须升级为 P1，不能拆散规避阻断条件。

## 4. 有效报告标准

### 4.1 独立评分报告

A、B、C 的报告同时满足下列条件才有效：

1. 正文 SHA 与量表 SHA 均匹配本轮锁定值；
2. 明确声明只接触盲评量表内联内容与匿名正文内联内容；
3. 没有接触测试根路径、正文源文件名、目标说明、作者身份、主笔包、任务卡、协调规则、事实报告、真人感报告或其他评分者输出；
4. 五个分项均为整数，并分别落在 20、20、20、25、15 的上限内；
5. 总分等于五项算术和；
6. 正文 CJK 计数、正文起止、前300边界、事实分类与证据格式齐全；
7. 每维核心项数量、落档、档内加减分和最终分数可以互相复算；
8. 报告在任何互盲信息揭示之前锁定。

### 4.2 事实与真人感报告

审校报告同时满足下列条件才有效：

1. 正文 SHA 匹配；
2. 每个问题记录 P0、P1 或 P2 中唯一一个级别；
3. 每个问题包含正文位置、短证据、违反的具体规则、阅读或连续性影响、可执行修法；
4. 报告分别汇总 P0、P1、P2 数量，算术与问题列表一致；
5. 非必写事实未提没有被误报为问题；
6. 未读取其他审校或开篇评分结果后再反向调整问题级别。

## 5. 缺失、污染与错误报告的处理

### 5.1 缺失报告

- 未提交报告，或缺少 SHA、分项、证据、隔离声明、问题级别等必需内容，均视为报告缺失。
- 缺失报告不记零分，也不与有效报告合并；协调人重新派发同一锁定载荷给新的独立人员。
- A 或 B 任一报告缺失时，评分流程未完成，不能用另一人的结果单独判定。
- 事实或真人感报告缺失时，总放行流程未完成。

### 5.2 污染报告

出现以下任一情况即为污染：

- 评分者看到测试根路径、正文源文件名、目标说明、协调规则或任何非盲材料；
- 评分者看到其他评分者身份、分数、证据或评语；
- 报告完成前参与尺度讨论或收到暗示性修分要求；
- 使用与锁定 SHA 不同的正文或量表；
- 事实、真人感审校在定级前读取开篇分数并据此调整结论。

污染报告立即作废，不得通过删掉污染段落、口头保证独立或人工修分恢复有效性。A、B 污染时分别重派新的独立人员；C 污染时必须重派新的 C，直至取得一份有效第三评分。

### 5.3 算术或格式错误

- 仅有算术错误且输入、证据和隔离均有效时，评分者可在互盲解除前提交一次带原因的更正记录；原始记录保留，协调人复算。
- 分档依据、证据或核心项缺失不属于纯算术错误，按缺失报告处理并重新派发。
- SHA 不匹配不是格式错误，按污染或版本错误作废。

## 6. 开篇分数判定

协调人只使用有效的独立评分报告，严格按以下顺序处理：

1. 先验证 A、B 的隔离、SHA、字段、算术与证据。任一无效则重派，直至获得有效 A 与有效 B。
2. 若 A、B 任一总分低于 90，开篇分数门不通过，不派 C。
3. 若 A、B 均不低于 90，且两者绝对分差不超过 5，开篇分数门通过。
4. 若 A、B 均不低于 90，但两者绝对分差超过 5，派发 C。
5. C 有效后，将 A、B、C 三个总分从小到大排序，取中间值作为最终爆款分。
6. 最终爆款分不低于 90，开篇分数门通过；低于 90，开篇分数门不通过。
7. C 报告污染、缺失或 SHA 不匹配时，该 C 无效，必须重派；不能使用无效 C 计算中位数。

A、B 的平均分不参与任何放行判断，不作为附加条件，也不用于替代中位数。

## 7. 总放行条件

只有以下条件同时成立，协调人才可记录本轮通过：

1. 开篇分数门按第6节通过；
2. 有效事实与连续性报告为 P0=0、P1=0；
3. 有效真人感与反过描写报告为 P0=0、P1=0；
4. 正文为 2100—2300 个 CJK 统一汉字；
5. 全文姜瑶贴身第三人称；
6. 三次攻防、唯一身体限制、停止索折、打开院门、实际离院、兑现后核谎新命令、骑车抢跑且核谎未完成全部成立；
7. 主笔交付、章后状态增量与所有有效报告记录的是同一正文 SHA；
8. 本轮没有未处理的缺失、污染或版本不一致报告。

P2 可以保留在报告中，不单独阻断放行；但同模式累计达到升级规则时必须先升级为 P1，再执行 P0=0、P1=0 的条件。

## 8. 判定顺序与状态记录

协调人按以下顺序记录，避免先看分数后改事实级别：

1. 锁定匿名正文 SHA 与盲评量表 SHA；
2. 分别派发 A、B，并独立派发事实与真人感审校；
3. 先收齐并锁定所有原始报告，不互相披露；
4. 验证报告有效性，缺失或污染则重派；
5. 锁定事实与真人感 P0、P1、P2 数量；
6. 执行 A、B 分数规则，必要时盲派 C；
7. 执行总放行条件；
8. 记录通过、不通过或流程未完成及其唯一直接原因，不用说明替代正文修复。

## 9. 协调人提交清单

每轮记录必须包含以下已完成信息，不使用空白占位：

- 匿名正文 SHA、盲评量表 SHA、正文 CJK 统一汉字数；
- A、B 及必要时 C 的报告有效性、五项分数、总分和隔离声明；
- A、B 绝对分差；启用 C 时记录三者排序与中位数；
- 事实报告 P0、P1、P2 数量及报告有效性；
- 真人感报告 P0、P1、P2 数量及报告有效性；
- 所有缺失、污染、SHA 不一致与重派记录；
- 开篇分数门结论、事实门结论、真人感门结论与总放行结论；
- 未通过时只列当前最高级别、最先需要修复的直接原因。
