# 《穿越八零：军婚女配要翻身》第一章真人感审校任务卡 v1.6

用途：第001章真人感、叙述自然度与反过描写独立审校

## 1. 输入隔离

1. 审校者只读取 `第一章重构_封闭主笔包_v1.6.md` 与 source_file 正文，并使用本任务卡提交报告。
2. 不读取旧稿、外部规划、事实审校报告、开篇盲评分数、协调规则、聊天记录、原著或其他审校者输出。
3. 不因平台目标或分数预期调整 P 级；只依据 source_file 的可观察文字和封闭包已锁定的视角、人物声线、反过描写与结构边界判断。
4. 本任务只诊断并给局部修法，不直接执行 Humanizer-zh 改写，不新增剧情、证据、人物、能力或经营事实。
5. 章末状态快照不计入叙事自然度，但若正文把审校说明、状态字段或任务语言混入叙事，按本卡定级。

## 2. 哈希与版本身份

- `source_file_sha256`：source_file 原正文文件未经改写的原始字节 SHA-256。换行、编码、标题、标点或章末状态快照任一变化都会改变该值。
- `naturalness_card_sha256`：本任务卡文件原始字节 SHA-256。
- 真人感报告只计算并记录 source_file_sha256 与 naturalness_card_sha256；不得使用 anonymous_payload_sha256 替代 source_file_sha256。
- 审校者不读取manifest、不自行判断版本是否匹配；协调人负责将报告中的两个哈希与manifest比对并处理版本不符。

## 3. 审校范围

### 3.1 视角与语义可用性

- 全文保持姜瑶贴身第三人称，不进入其他人物内心，不突然切成全知讲解者。
- 句子、指代、动作主体和因果关系可被正常理解，不出现连续语义断裂。
- 婚房、堂屋、院内、院门与自行车的转场在语言层面连贯；读者无需依赖任务卡补齐谁移动、谁开门、谁持钥匙。
- 关键攻防仍是人物现场行动，不被写作说明、总结标签或抽象结论替代。

### 3.2 叙述验收腔

重点检查：

- 旁白逐项登记对手没报金额、没认借款、没定还期，替读者验收任务；
- 回击之后由旁白解释姜瑶为什么赢、这意味着什么或关系已经怎样变化；
- 段尾频繁总结本段功能、风险、信息差或下一步因果；
- 正文混入规则、清单、分数、报告字段、模型自述或协作交流痕迹。

责任结果必须从打断、回避、改口、钥匙转手和人物行动中显露，不能靠验收式旁白盖章。

### 3.3 清单化与模板化

- 第二击必须保留金额、谁借、谁还、何时还的功能先后，但不能写成整齐背诵、同句式四连问或现代审讯提纲。
- 对手允许答非所问、插话、改口和临时防守；四人不能同时拥有完整、正确、现代化的论证。
- 段落结构不能机械重复成对手一句、姜瑶一问、旁白一总结的同一循环。
- 不为显得全面而强行三段式、否定式排比或连续金句。

### 3.4 人物身份声线

- 姜瑶称谓软、落点硬，追家常责任，不辱骂、不使用法律教科书或现代网络梗。
- 沈桂兰以家长伦理、吃住、孝顺、家里规矩与控制权说话。
- 沈建勋以生意急需、周转后有好处回避借款边界，语言服务自身利益，不突然认下全部目的。
- 陈丽维护孩子钱和自家账，切割丈夫债务但不变成姜瑶盟友。
- 三名对手不能只是同一种刻薄声音；同一信息不能由四人轮流复述。

### 3.5 反过描写与过描写

- 全章唯一有效身体限制是姜瑶眼前发黑并被迫在堂屋坐下。
- 不用摸存折、按暗袋、硌着、衣料触感、湿鞋、冷热、胸喉、手指等无功能感官确认资产或情绪。
- 不连续使用感官或触感、比喻、心理总结三联链。
- 小动作、环境句、心理句删去后若不改变压力、资源、关系或下一步因果，应删除。
- 不在叙述、对白、心理三个层面重复同一信息。
- 不靠整排震惊、突然证据、群众认证、巧合救兵或对手降智制造结果。

### 3.6 节奏与衔接

- 关键选择、钥匙转手、身体限制、姜远牺牲、停止索折、院门打开、沈桂兰让开、跨门离院与骑车抢跑可适当放慢。
- 无功能转场、重复信息和流水动作快速略过。
- 兑现与反制次序清楚：停止索折，院门实际打开，沈桂兰让开，姜瑶离院，沈桂兰再下核谎命令，沈建勋骑车抢跑；不锁定谁亲手开门，非沈桂兰开门不构成真人感问题。
- 结尾贴住已经发生的抢跑，不补姜瑶总结、预案、泛化感悟或额外钩子。

## 4. P0／P1／P2定义

同一问题只记一个最高级别；相同证据不得拆成多个问题重复累计。

### P0：严重断裂，正文不可用

任一项成立记 P0：

- 视角持续越出姜瑶，进入他人内心或切成全知讲解，覆盖一个核心场景以上；
- 连续语义、指代或动作主体断裂，导致核心场景无法判断谁在做什么；
- 提示词、任务清单、评分语言、模型自述或报告字段进入叙事；
- 全章人物大面积变成同一论证声音，核心攻防无法作为人物现场行为成立；
- 文本需重写一个以上核心场景才能恢复可读性；
- 其他严重真人感问题使正文无法作为小说章节使用。

### P1：实质损伤场景，需要修文

任一项成立记 P1：

- 叙述验收腔反复替读者登记任务完成情况；
- 第二击清单化、整齐背诵或现代审讯化，人物临场反应消失；
- 沈桂兰、沈建勋、陈丽出现人物身份同声，至少两人无法凭利益与用词区分；
- 无功能感官、三联链、重复心理或动作堆叠形成过描写；
- 场景切换、钥匙转手、开门、离院或抢跑存在衔接硬伤，读者需要回读才能拼出动作；
- 姜远牺牲段落膨胀成长篇道德训话、煽情总结或集体表态；
- 核心动作被解释性旁白、连续金句、抽象意义或通用积极结论淹没；
- 同模式 P2 达三处，或跨越两个场景。

P1 阻断真人感门，修文后必须针对同一 source_file 新版本重审。

### P2：局部偏好与可选优化

只在问题孤立、没有改变视角、语义、人物身份、核心动作和追读断点时记 P2，例如：

- 一处可删的小动作、环境句或同义重复；
- 一处略现代、略完整或节奏偏齐的句子；
- 一处不影响理解的连接词、指代或段落长短偏好；
- 一处孤立的感官、比喻、验收式旁白或通用AI词汇。

P2 不独立阻断；相同模式累计达升级条件时必须转为 P1。

## 5. 完整真人感报告模板

### 5.1 报告头字段

| 字段 | 必填值与格式 |
|---|---|
| report_schema_version | 固定写 `1.0` |
| report_file_name | 使用第6节锁定的精确文件名 |
| input_isolation_statement | 固定声明：仅阅读 `第一章重构_封闭主笔包_v1.6.md`、source_file 与 `第一章真人感审校任务卡_v1.6.md`，未阅读旧稿、外部规划、事实报告、盲评分数、协调规则、聊天记录或原著 |
| source_file_name | 由协调人提供的原正文精确文件名；审校者不读取manifest |
| source_file_sha256 | 原正文文件原始字节的64位小写SHA-256；不得填写匿名载荷哈希 |
| naturalness_card_file_name | 固定写 `第一章真人感审校任务卡_v1.6.md` |
| naturalness_card_sha256 | 本任务卡文件原始字节的64位小写SHA-256 |

审校者只报告自身P级与证据，并只计算 source_file_sha256、naturalness_card_sha256；不读取盲评报告或manifest，不判断任何HR。

### 5.2 每题记录

| 字段 | 必填内容 |
|---|---|
| issue_id | 按正文顺序使用 N-001、N-002 递增编号 |
| location | 正文 CJK 起止序号与段落定位 |
| evidence | 不超过20个CJK汉字的原文短引 |
| category | 视角语义、验收腔、清单化、人物身份同声、过描写、衔接硬伤或局部偏好中的一项 |
| p_level | P0、P1、P2中的一项 |
| scope | 孤立一处、同场景多处、跨场景或全章 |
| impact | 说明对人物可信度、阅读连贯、节奏或追读的影响 |
| required_fix | 一条局部可执行修法；不得改变封闭包事实、三击顺序和章末状态 |

### 5.3 汇总与放行

| 字段 | 计算与结论 |
|---|---|
| issue_total | 问题记录总数 |
| p0_count | P0记录数 |
| p1_count | P1记录数 |
| p2_count | P2记录数 |
| arithmetic_check | issue_total等于p0_count、p1_count、p2_count之和时写通过，否则报告无效 |
| repeated_pattern_check | 列出同模式数量与分布场景，达到升级条件时记录已升级 |
| release_decision | P0=0且P1=0时写真人感门放行；否则写真人感门不放行 |
| release_reason | 放行时写无阻断项；不放行时只列最高P级的首要问题issue_id |
